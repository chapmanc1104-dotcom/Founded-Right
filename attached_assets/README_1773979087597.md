# BizLaunch — Business Setup Platform

Structure your LLC for grants, loans, and government contracts.
Full-stack React + Supabase + Claude AI app with real user accounts,
cloud sync, and personalized funding discovery.

## Quick start (5 steps)

### Step 1 — Install dependencies

```bash
npm install
```

### Step 2 — Create a Supabase project

1. Go to [supabase.com](https://supabase.com) and create a free account
2. Click **New project** — give it a name (e.g. `bizlaunch`)
3. Choose a region close to your users (US East for Maryland)
4. Wait ~2 minutes for the project to spin up

### Step 3 — Run the database migration

1. In your Supabase dashboard, click **SQL Editor** in the left sidebar
2. Click **New query**
3. Open `supabase/migrations/001_initial_schema.sql` from this project
4. Paste the entire contents into the SQL Editor
5. Click **Run** — you should see "Success. No rows returned"

This creates all 6 tables with Row Level Security so users can only
access their own data.

### Step 4 — Configure environment variables

```bash
cp .env.example .env.local
```

Open `.env.local` and fill in:

```env
# From Supabase: Project Settings → API
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here

# From console.anthropic.com → API Keys
VITE_ANTHROPIC_API_KEY=sk-ant-...
```

**Where to find your Supabase keys:**
- Dashboard → Your project → Project Settings (gear icon) → API
- Copy `Project URL` and `anon public` key

**Where to find your Anthropic key:**
- [console.anthropic.com](https://console.anthropic.com) → API Keys → Create key

### Step 5 — Run the app

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## App features

| Screen | What it does |
|---|---|
| **Dashboard** | Setup score ring, progress by category, urgent action items, funding matches |
| **Checklist** | 46-step setup checklist across 8 categories, filterable |
| **Documents** | Vault tracking which docs are uploaded vs missing |
| **Presence** | Professional presence checklist — domain, email, website, capability statement |
| **NAICS Finder** | AI describes NAICS codes from plain-English business description |
| **Live Grants** | AI-generated funding matches personalized to your profile |
| **Calendar** | Deadline calendar for filings, grant deadlines, renewals |
| **AI Assistant** | Claude with full business profile context for specific advice |

---

## Database schema

| Table | Purpose |
|---|---|
| `profiles` | Business info, owner details, funding goals, certifications |
| `checklists` | Per-item completion status with timestamps |
| `naics_codes` | User's saved NAICS codes from the finder |
| `grant_cache` | Cached AI-generated funding matches |
| `chat_messages` | Persisted AI assistant conversation history |
| `applications` | Application tracker (program, status, deadline, notes) |

All tables have **Row Level Security** — users can only read/write their own rows.
A database trigger auto-creates a profile row when a new user signs up.

## Deploying to production

### Option A — Vercel (recommended, free tier available)

```bash
npm install -g vercel
vercel
```

When prompted, add your environment variables in the Vercel dashboard:
Settings → Environment Variables → add `VITE_SUPABASE_URL`,
`VITE_SUPABASE_ANON_KEY`, `VITE_ANTHROPIC_API_KEY`

### Option B — Netlify

```bash
npm run build
# Drag the dist/ folder to app.netlify.com/drop
# Add env vars in Site Settings → Environment Variables
```

### Option C — Any static host

```bash
npm run build
# Upload the dist/ folder to S3, Cloudflare Pages, GitHub Pages, etc.
```

## Security note for production

The `VITE_ANTHROPIC_API_KEY` is currently used directly in the browser
for development convenience. **Before going public**, move AI calls
to a backend function so the key is never exposed in the bundle.

**Recommended approach with Vercel:**

1. Create `api/ai.js` (a Vercel Edge Function):

```js
export const config = { runtime: 'edge' }

export default async function handler(req) {
  const { messages, system, maxTokens } = await req.json()
  const res = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': process.env.ANTHROPIC_API_KEY,
      'anthropic-version': '2023-06-01',
    },
    body: JSON.stringify({ model: 'claude-sonnet-4-20250514', max_tokens: maxTokens || 1000, system, messages }),
  })
  const data = await res.json()
  return new Response(JSON.stringify(data), { headers: { 'Content-Type': 'application/json' } })
}
```

2. In `src/lib/ai.js`, change the fetch URL to `/api/ai` and remove the API key header.
3. Set `ANTHROPIC_API_KEY` (without `VITE_` prefix) in Vercel — it stays server-side only.
